```ts title="server.ts"
import { createOctaPointClient } from '@octap/sdk';

const client = createOctaPointClient({
  baseUrl: process.env.OCTAP_API_URL,
  credentials: { apiKey: process.env.OCTAP_API_KEY },
});

const earn = await client.earnPoints({
  organizationEndUserId: memberId,
  purchaseAmount: 100000,
  idempotencyKey: 'order-42',
});
// earn.status === 'PENDING', earn.estimatedPoints === 1000 với tỷ lệ earn 1%
```

## Ba quy tắc cần nhớ

1. **Giữ API key trên server.** Browser SDK không bao giờ cần đến nó.
2. **Pending chưa phải kết quả cuối.** Điểm chỉ tiêu được, và voucher trả phí chỉ thuộc về khách hàng, sau khi chain xác nhận. Xem [Vòng đời điểm](/vi/concepts/points-lifecycle/).
3. **Thử lại với cùng key.** Khi gặp lỗi không rõ nguyên nhân, hãy đọc trạng thái hiện tại, rồi gửi lại request với cùng idempotency key. Xem [Idempotency và phục hồi](/vi/concepts/idempotency-and-recovery/).
