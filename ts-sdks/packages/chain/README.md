# @octap/chain

Backend-only wrapper around the `octap` Move package (`contracts/sui`). Not published, not a
dependency of `@octap/node` or `@octap/browser` — only the API's `infra/clients/sui` layer imports
it, so object ids, capability types, and raw on-chain amounts never leak past that boundary (see
`src/client.ts`'s module doc).

## Regenerating bindings

`src/contracts/` is generated by [`@mysten/codegen`](https://www.npmjs.com/package/@mysten/codegen)
from `../../../contracts/sui`. After changing the Move source or publishing a new package version:

```sh
npm run codegen --workspace @octap/chain
```

This also runs `scripts/fix-codegen-windows-imports.mjs`, which patches a real bug in
`@mysten/codegen` 0.12.19: on Windows it emits a malformed relative import
(`./src\contracts\utils\index.js`) for every generated module instead of `../utils/index.js`. Don't
hand-edit anything under `src/contracts/` otherwise — it says "DO NOT MODIFY" for a reason, this
one exception is scripted specifically so it reapplies after every regeneration.

Update `src/constants.ts` and `contracts/sui/DEPLOYMENTS.md` together whenever the package is
published or upgraded.

## Transport

Uses `SuiGrpcClient` from `@mysten/sui/grpc` (gRPC-Web over `@protobuf-ts/grpcweb-transport`),
matching `docs/architecture.md`'s "Sui gRPC adapter". `SuiJsonRpcClient` was tried first and
rejected after a live test against testnet: public fullnodes have already fully decommissioned
JSON-RPC (`getCoins` returns `-32601 Method not found`, not a soft-deprecation warning) — so this
isn't a "migrate eventually" item, gRPC is the only transport that currently works.
